# Evolution X for Xiaomi 17 Ultra

An evidence-first workspace for bringing Evolution X to Xiaomi 17 Ultra and
investigating how much of the stock Xiaomi feature set can be retained.

This is an unofficial bring-up, not a ready-to-flash ROM. No phone should be
unlocked, wiped, or flashed as part of workspace setup.

The setup will keep build tooling, source revisions, device research, and stock
feature evidence separate. Full Android builds require a supported Linux x86-64
host and a case-sensitive filesystem; this Mac is the research/control host.

Run the workspace tests with:

```sh
python3 -m unittest discover -s tests -v
```
